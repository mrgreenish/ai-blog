# Community outreach drafts

These are draft starting points. Do not publish them automatically. Adapt each
message to the community's rules and answer an existing question before
sharing a link.

## Jira and Cursor communities

Cursor's native Jira integration removes the copy/paste step, but a vague
ticket still produces a vague agent run. I put together a practical guide and
copyable ticket template covering native Jira, manual handoff, custom MCP/API
routing, permissions, stop conditions, and PR evidence:

https://www.aifieldnotes.dev/chapters/jira-to-cursor

## Storybook, Figma, and design-system communities

The Storybook design-token addon documents tokens already present in
stylesheets; it is not a Figma synchronization layer. This walkthrough shows
the boundary between Figma MCP, a committed semantic-token mapping, production
CSS, component stories, and the addon. It includes a reusable token-mapping
skill:

https://www.aifieldnotes.dev/chapters/design-to-storybook

## AI coding and code-review communities

Clean AI-generated code can still be wrong at boundaries the prompt never
named. I consolidated my review notes into a four-pass workflow for behavior,
security/data, tests, and AI/human review, plus a downloadable PR checklist:

https://www.aifieldnotes.dev/chapters/diff-review-loops
