# Tool flow, usefulness, and design review

Reviewed the ten public tools on September 11, 2026. `git pull --ff-only` reported that the repository was already up to date. Changes are local and have not been deployed.

## Changes by tool

| Tool | Main issues found | Result |
| --- | --- | --- |
| Workflow Finder and Recipes | Changing modes discarded the chosen recipe or guided result; focus could be lost between questions. | Both modes retain progress, questions hand focus to the next step, and results remain copyable. |
| Model Picker | Progress relied on dots; results could not be copied; returning from results required starting over; old answers lingered during transitions. | Visible question count, keyboard focus management, copyable recommendations, and a “Change last answer” action. |
| Model Personalities | Random matching removed saved choices; reaching examples required reviewing every card; the last scripted reply left an unfinished conversation. | Browse any model, save a deterministic shortlist, remove candidates, and copy the shortlist. Scripted examples are clearly labeled and have a working final action. Removed the simulated matchmaking delay and GSAP interaction layer. |
| Model Compare | Disabled preview, cramped comparison tables, and mostly missing benchmark records. | Editable context segments, clear capacity checks, and a copyable model evaluation checklist. Only recorded historical columns are displayed when available; missing records are not represented as scores. |
| Cost Calculator | Fixed token assumptions; narrow mobile bars squeezed out values; no export. | Editable token counts, explicit daily frequency and 30-day assumptions, accurate token labels, readable stacked mobile rows, and copied estimates. |
| Model Mixer | Assumed mixed workflows always succeeded first time; repeated the same controls in three responsive trees; unlabeled model selectors; no export. | Independent attempt assumptions for mixed and single-model workflows, one responsive control tree, labeled selectors, retained mode state, and a copied pipeline. Defaults to the pipeline builder. |
| Context & Cost Explorer | Out-of-capacity and empty requests still appeared to support meaningful request counts; numerical maxima were not enforced in state. | Bounded inputs, explicit empty and over-capacity messages, clear API budget wording, and a copied request estimate. |
| Scenario Lab | Missing selected/disclosure semantics; no reusable takeaway; the planning indicator could become too wide. | Pressed states, named disclosures, wrapped planning steps, distinct result state per mode, copied takeaways, and visible evidence limitations. |
| Failure Gallery | The reveal overlay covered code the reader needed to inspect; prevention panels lacked disclosure semantics; no export. | Full code stays visible, the reveal control sits below it, prevention panels expose their state, and prevention guidance can be copied. |
| Config Generator | Static, disabled mockup. | Working AGENTS.md, CLAUDE.md, and Cursor rule templates with stack selection, editable commands and conventions, a selectable preview, and clipboard output. |

## Shared design and implementation

- Nine direct tool pages join the existing workflow page. The directory groups all ten tools by purpose and identifies what each gives the reader. Each tool links to a companion guide.
- Page metadata and the sitemap include the new pages. A shared catalog supplies the directory, static route generation, and metadata.
- Direct pages load their interactive component on demand. The title, explanation, and companion link remain server rendered. Client rendering at the lazy boundary avoids an observed `useId` hydration mismatch on first load.
- Extracted the quick estimator from Model Mixer. Removed the mixer’s animation dependency and duplicate responsive controls.
- Improved mobile control sizing, number alignment, selectable code, focus visibility, input labels, and sticky-header anchor offsets. Cost bars no longer animate width; model/scenario details and prevention panels use opacity transitions instead of animating height.
- Fixed stale clipboard success feedback after a subsequent copy failure.
- Existing MDX embeds remain supported. PromptLab and DevBenchmark are compatibility aliases for Scenario Lab, not additional standalone tools.

## Verification

- Full suite: **146 tests passed**, including eight new regression tests for the changed flows and updated sitemap coverage.
- TypeScript: `pnpm exec tsc --noEmit` passed.
- ESLint: no warnings or errors in the source checks.
- Browser: completed every tool’s main flow, including clipboard output, keyboard picker progression, invalid/empty request inputs, planning mode, shortlist completion, and recipe/pipeline state retention.
- Responsive sweep: all ten tools at **320, 768, and 1280 px**. No document overflow and no unlabeled visible form controls in all 30 checks.
- A fresh browser session reported **zero console warnings or errors** during the responsive sweep. Desktop and mobile screenshots were inspected.
- Production build: **passed from an isolated snapshot**, with all **165 pages** generated. All ten tool routes and the existing reasoning/agents article embeds also rendered successfully from that production build, with zero console warnings or errors. The initial shared-workspace build compiled but failed on a missing generated `/_document` module; isolation avoided the shared output problem.

## Scope and limitations

The model registry, prices, and editorial model judgments were reused, not independently re-audited. Suggestions and examples remain identified as editorial or illustrative. Generated instructions are templates, not enforcement mechanisms. Tool selections are local to the current page session; copying preserves the output. Changes observed in the shared chapter layout during this task belong to concurrent work and were preserved.
