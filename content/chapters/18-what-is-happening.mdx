A screenshot, a German document, a failing test: each asks something different of an AI system. The recent releases make those choices more concrete. Mistral Large 4 adds a European multimodal API candidate, Kolibri focuses on German and English with published weights, and OpenAI's Decisions API turns text and images into bounded answers your application can use.

The surrounding tools still matter. Context, acceptance checks, browser control, and recovery determine whether a capable model produces a useful result. These updates cover both the models and the harnesses around them.
